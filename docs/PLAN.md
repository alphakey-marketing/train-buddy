# Train Buddy 項目規劃

目標：一個手機 App，有個 3D 人形陪你一齊做運動。你可以由背面（或者側面、正面）睇佢點樣伸展、訓練，同時見到邊啲肌肉用緊力。

## 技術選擇

| 部分 | 選擇 | 原因 |
|---|---|---|
| App 框架 | Expo + React Native (TypeScript) | 一套 code 出 iOS、Android、Web；用 Expo Go 喺手機即刻試 |
| 3D 顯示 | three.js + @react-three/fiber (expo-gl) | 手機上最成熟嘅 3D 方案，之後可以直接載入 GLB 人體模型 |
| 動作數據 | 自家關鍵幀格式（`src/data/exercises.ts`） | 原型階段簡單易改；之後可以換做骨骼動畫檔 |
| 之後嘅後端 | Firebase / Supabase（第 3 階段先決定） | 用戶帳戶、課程、訓練紀錄 |

## 點樣加新動作

基本動作喺 `src/data/exercises.ts`，動作庫喺 `src/data/library/`。加一個 `Exercise`（類型睇 `src/data/types.ts`），`group` 決定佢喺邊個分類出現；`steps`、`checks`、`why`、`caution` 會顯示喺「說明」面板：

1. 列出用到嘅肌肉同比重（1 = 主要，0.5 = 輔助）
2. 寫幾個關鍵幀：時間（秒）、姿勢、用力程度（0–1）、提示文字
3. 最後一個關鍵幀要返回第一個姿勢，咁先會順暢循環

角度單位係弧度，方向定義寫咗喺 `src/lib/pose.ts` 最頂。全身控制：`tilt`（向前傾，約 1.4 = 俯臥）、`twist`（轉身）、`shift`（橫移）、`lift`（跳起高度）、`seat`（1 = 坐地）、`lAnkle`/`rAnkle`（正數 = 踮腳）、`lToe`/`rToe`（正數 = 屈趾，負數 = 反趾）。

# 身體動：動作同訓練計劃

更新日期：2026-11-09
用途：之後做動作（3D 關鍵格）同寫處方邏輯（`src/lib/prescribe.ts`），都以呢份做準。

> 健康聲明：呢份係一般健身建議，唔係醫療診斷或者治療。有傷、懷孕、心臟病、高血壓未受控、近期做過手術，或者做嘅時候覺得痛、暈、心口翳，就要停，去問醫生或者物理治療師。上線前要請物理治療師覆核。

---

## 0. 總原則

1. **研究同指引做主**，其他來源只借概念同動作類型。
2. **動作用通用名同自己嘅說明**：唔用 P90X3 嘅課程名、商標（例如「Muscle Confusion」），唔用中野崇本書嘅名或者編號。
3. **每個動作要有證據等級**，app 唔講冇證據嘅功效。
4. **份量比動作重要**：揀啱份量（每星期幾多分鐘、幾多組），好過揀「神奇動作」。
5. **用家肯做先有效**：寧願易少少、短少少，都要做得到、做得耐。

### 份量規則（全 app 通用）

| 目標 | 份量 | 出處 |
| --- | --- | --- |
| 柔軟度 | 每個部位每星期靜態拉 **5 分鐘以上**，分 **5 日或以上**做（例如每日 30–60 秒 × 1–2 次） | Thomas 2018 |
| 柔軟度（另一條路） | 全幅度力量訓練，效果同拉筋差唔多 | Afonso 2021 |
| 寫字樓頸膊痛 | 橡筋帶力量訓練，**每日 2 分鐘、每星期 5 日**都有效 | Andersen 2011 |
| 久坐 | 每 **20–30 分鐘**起身郁 2 分鐘（輕鬆行都得） | Dunstan 2012 |
| 慢性腰痛 | Pilates 式核心、McKenzie、核心強化效果最好（證據低至中）；份量多啲效果好啲 | Hayden 2021 |
| 長肌肉 | 每組肌肉每星期 **≥ 10 組**效果最好；新手 4–10 組已經有效；每組做到仲剩 1–3 下就做唔到 | Schoenfeld 2017 |
| 力量訓練次數 | 每組肌肉每星期 **2 次或以上** | ACSM、WHO 2020 |
| 有氧 | 每星期中等強度 **150–300 分鐘**，或者高強度 75–150 分鐘 | WHO 2020 |
| 高強度間歇 | 短時間全力衝刺，例如 10 分鐘入面做 3 × 20 秒，對心肺有效（待核對） | Gillen 2016 |

**中等強度點分**：講到嘢，但唱唔到歌。**高強度**：講唔到完整句子。

## 1. 三個來源借咩

### 1.1 中野崇（身體操作）
現有 34 個動作入面，29 個嚟自呢本書，已經全部改咗名。

- **借**：基盤調整（腳趾、脊骨、胸廓、膊胛嘅活動）、脫力（放鬆、甩手甩腳）、四要素同複合動作（落地反應、轉身發力）、爆發動作（彈跳、急停）。
- **用法**：
  - 放鬆、活動度：寫字樓同瞓前。
  - 四要素、爆發：中級以上嘅「運動表現」堂，用家要先有基本力量。
- **證據**：屬教練經驗，冇隨機對照研究直接驗證，所以等級係 **C**。app 只可以講「放鬆」「郁動」，唔講「矯正」或者「治療」。

### 1.2 P90X3（只借結構，唔借內容）
- **借**：
  - **30 分鐘一堂**：包括熱身、主要部分、收操。
  - **分 block**：3 星期加份量，第 4 星期減量恢復。
  - **一星期混合**：力量、心肺、瑜伽、活動度。
  - **訓練方法**：
    - 等長（hold 住唔郁）
    - 離心（慢慢放落）
    - 超級組（兩個動作輪流做）
    - 低衝擊敏捷步法
- **唔借**：
  - 課程名同商標
  - 動作編排
  - 「肌肉混淆」講法：冇科學根據，重點係**逐步加重**，唔係不停換動作
  - 每星期練 6 日：對新手太多

### 1.3 Ben Greenfield（只借有證據嘅部分）
- **借**：
  - **微運動（movement snacks）**：一日入面不時做少少，例如做 10 下深蹲、行一層樓梯。
  - **中等強度有氧**：佢叫 zone 2。
  - **少量高強度間歇**。
  - **壺鈴擺盪、負重行**：簡單、全身、慳時間。
  - **慢呼吸放鬆**。
  - **重視瞓覺**：瞓前做放鬆練習。
- **唔借**：
  - 營養補充品
  - 冷水浸
  - 極端禁食
  - 各種「biohack」器材

## 5. 退階同進階（做唔到就換易啲，做得太易就換難啲）

規則：所有組都做到次數上限，下次就**加次數 → 加組數 → 換難一級 → 加重**。做唔到次數下限，就換易一級。

| 鏈 | 由易到難 |
| --- | --- |
| 推 | 推牆掌上壓 → 撐枱掌上壓 → 跪姿掌上壓 → 掌上壓 → 掌上壓半路 hold／慢放 |
| 拉 | 橡筋帶划船 → 反向划船（高槓）→ 反向划船（矮槓）→ 引體上升慢放 → 引體上升 |
| 蹲 | 坐低企起 → 深蹲 → 慢放深蹲 → 分腿蹲 → 後腳放椅分腿蹲 |
| 髖 | 臀橋 → 單腳臀橋；徒手折髖 → 壺鈴硬拉 → 啞鈴羅馬尼亞硬拉 → 壺鈴擺盪 |
| 核心 | 死蟲式 → 跪姿伸手伸腳 → 跪姿平板撐 → 平板撐 → 側平板撐 → 船式 hold |
| 跳 | 低衝擊開合 → 開合跳 → 深蹲跳 → 中野爆發系列 |
| 頸膊 | 收下巴 → 橡筋帶側平舉、聳膊 → 加粗啲嘅橡筋帶 |

## 8. 處方規則（寫入 `prescribe.ts`）

### 8.1 入面要填嘅資料
程度、場地、器材、有幾多時間（1、2、5、10、15、20、30 分鐘）、測試結果（邊度緊、邊度痛）、禁忌、最近 7 日做過咩。

### 8.2 點樣揀一套
1. **過濾**：場地同器材唔夾、級數高過用家、中咗禁忌，全部剔走。
2. **配套**：按時間揀第 6 節最近嘅一套；冇合適嘅，就用砌積木方法：熱身 → 主要 → 收操。
3. **按測試結果換動作**：
   - 例如測到膕繩肌緊：將收操換成 supine-hamstring 或者 seated-hamstring。
   - 例如頸膊痛：每日加 O4。
4. **計份量**：追蹤每個部位每星期：
   - 靜態拉咗幾多分鐘，目標 ≥ 5 分鐘
   - 每組肌肉練咗幾多組，目標新手 4–10 組，之後 ≥ 10 組
   - 有氧幾多分鐘，目標 150 分鐘
   - 未夠就優先補。
5. **唔重複**：同一個「動作鏈」入面，換同級嘅另一個動作。不過**主要力量動作要維持 3 星期**，方便逐步加重（唔玩「肌肉混淆」）。
6. **調整**：
   - 每次練完問「易／啱／難」同痛唔痛。
   - 連續 2 次「易」：進階一級。
   - 「難」或者痛：退階一級。
   - 痛分上升 2 分或以上：停嗰個動作，並提議去問專業人士。

## 9. 安全

- **開始前問卷**：參考 PAR-Q+。有心臟病、胸口痛、暈、未受控高血壓、懷孕，就先問醫生。
- **即刻停嘅情況**：胸口痛、氣促到講唔到嘢、暈、麻痺、痛向手或者腳延伸、尖銳痛。
- **常見禁忌對應**：

| 情況 | 避開 | 改做 |
| --- | --- | --- |
| 急性腰痛 | toe-touch、db-rdl、kb-swing、負重彎腰 | prone-press-up、dead-bug、行路 |
| 手腕痛 | pushup 系列、prone-scapula-spiral、plank | wall-pushup（握拳）、band 動作 |
| 膝痛 | 跳躍、深蹲到底、pigeon | wall-sit（企高啲）、glute-bridge、step-up（矮級） |
| 膊頭痛 | shoulder-press、pullup、高舉過頂 | band-ext-rotation、band-row、wall-angel（細幅度） |
| 懷孕 | 瞓直、高衝擊、腹部發力 | 問醫生，app 唔出計劃 |

## 10. 製作次序（做動作 3D 關鍵格）

按「用得最多」同「證據強」排：

1. **第一批（寫字樓，12 個）**：
   - chin-tuck、upper-trap-stretch、seated-thoracic-ext
   - wrist-flexor-stretch、wrist-extensor-stretch
   - seated-twist、seated-figure4
   - sit-to-stand、standing-hip-flexor
   - doorway-pec-stretch、band-lateral-raise、band-shrug
2. **第二批（屋企力量同腰背，15 個）**：
   - cat-cow、child-pose、dead-bug、bird-dog
   - glute-bridge、plank-knee、plank、side-plank、prone-press-up
   - wall-pushup、desk-pushup、knee-pushup
   - reverse-lunge、prone-ytw、band-row
3. **第三批（瞓前、旅行，12 個）**：
   - supine-hamstring、supine-figure4、open-book、low-lunge
   - legs-up-wall、slow-breath、wall-sit、slow-squat
   - split-squat、hip-hinge、wall-calf-stretch、march
4. **第四批（器材同健身室、心肺）**：其餘動作。

## 定位同已定嘅決定

身體動要由「3D 動作示範庫」變成 **office 族嘅私人身體教練**：知你邊度緊、每日俾你 5 分鐘練習、俾你見到自己有進步。用家畀錢，係為咗感覺身體好咗；3D 公仔係令人信服嘅工具，唔係產品本身。

| 決定 | 內容 |
| --- | --- |
| 目標用家 | office 族：坐耐咗頸膊痛、腰緊、盤骨前傾、手腕攰 |
| 動作內容 | 動作本身可以自由用，但全部要改成自己嘅名稱同說明，唔再用書入面嘅名同編號（例如「ch4-01」） |
| 平台 | 網頁版先（gh-pages），回頭率證明有效先上 App Store／Google Play |
| 鏡頭糾正姿勢 | 之後先做（第 4 階段） |

## 第 1 階段：頭 15 分鐘（約 3–4 星期）

目標：新用家一開就覺得「呢個 app 明我」，15 分鐘內做完第一套練習，而且感覺到身體鬆咗。

1. **0–1 分鐘：一問**。3D 公仔已經喺度郁，只問一條：「邊度最唔舒服？」（頸膊／上背／腰／臀同大髀／手腕）
2. **1–5 分鐘：身體測試**。3–4 個簡單動作，用家睇圖自己揀結果：
    - 低頭下巴掂唔掂到心口
    - 雙手舉高貼唔貼到耳仔
    - 企直前彎掂到邊度
    - 深蹲蹲得幾低、腳踭離唔離地
3. **5 分鐘：身體地圖**。3D 公仔喺偏緊嘅位發紅光，配一句說明（例如「你胸口同髖屈肌偏緊，坐耐咗常見」）。呢張圖係第一個 wow 位，可以截圖分享。
4. **5–12 分鐘：第一套練習**。系統揀 4–5 個動作組成 5 分鐘，有聲帶住做、自動轉動作、倒數。
5. **12–15 分鐘：前後對比**。做之前同做之後自己打分（緊／痛 0–10），顯示「緊度由 7 跌到 4」。
6. **收尾**。設定每日提醒時間，顯示「連續第 1 日」同聽日練乜。

要做嘅功能：

- [x] 動作改名：34 個動作全部改成自己嘅名同說明，拎走書嘅編號
- [x] 每個動作加標籤：針對邊度（頸膊／腰…）、難度、需唔需要瞓地、可唔可以喺寫字樓做
- [x] 新用家流程：一問 → 身體測試 → 身體地圖
- [x] 處方引擎：由測試結果揀動作，組成 5 分鐘一套
- [x] 「跟住做」模式：全屏公仔、倒數、聲音提示（expo-speech）、自動轉下一個
- [x] 做前做後打分
- [x] 用手機本地儲存記住測試結果同紀錄（未使開帳戶）
- [x] 健康聲明：唔係醫療建議，有傷痛要睇醫生
- [x] 簡單數據追蹤：幾多人做完測試、做完第一套、第二日返嚟

完成標準：搵 10–20 個 office 朋友試，超過一半人做完第一套練習。

## 第 2 階段：令人每日返嚟（約 4–6 星期）

目標：由「試一次」變成「每日 5 分鐘嘅習慣」。

| 機制 | 點樣做 | 點解有效 |
| --- | --- | --- |
| 每日處方 | 每日唔同嘅 5 分鐘一套，跟身體地圖同上次打分調整 | 每日都有新嘢，唔使自己諗 |
| 寫字樓模式 | 2 分鐘、唔使瞓地、坐喺椅都做到嘅版本 | office 族最大障礙係冇時間、冇地方 |
| 連續日數 | 每星期有一日「請假」唔會斷 | 有動力但唔會壓力爆煲 |
| 每星期重測 | 同一組測試，身體地圖嘅紅色慢慢褪 | 最強嘅進步畫面 |
| 升級制 | 基本 → 初級 → 進階 → 挑戰，解鎖新動作 | 好似打機，有目標 |
| 肌肉紀錄 | 3D 公仔顯示「呢個星期練過嘅肌肉」 | 一個月之後成個人發光，有成功感 |
| 提醒 | 每日固定時間通知；坐咗 1 個鐘提你郁吓 | 將 app 帶入日常 |
| 分享 | 身體地圖前後對比圖、連續日數卡 | 免費宣傳 |

要做嘅功能：

- [ ] 每日處方（輪替動作，避免重複）
- [ ] 寫字樓模式（坐住做嘅動作組合）
- [ ] 連續日數同請假卡
- [ ] 每星期重測同前後對比
- [ ] 升級同解鎖
- [ ] 本週肌肉紀錄（3D 公仔）
- [ ] 網頁推送通知（PWA）
- [ ] 分享圖片
- [ ] 開帳戶（例如 Firebase），換手機唔會冇晒紀錄

完成標準：第 1 日回頭率 ≥ 40%，第 7 日回頭率 ≥ 20%。

## 第 3 階段：收月費（約 3–4 星期）

| 免費 | 月費版（建議 HK$48/月 或 HK$368/年） |

| 基本動作 | 全部動作同所有級數 |
| 每日 1 套固定練習 | 每星期重測同進度報告 |

## 指標、風險、下一步

要追蹤嘅數：

| 指標 | 目標 |
| --- | --- |
| 做完身體測試嘅比例 | ≥ 70% |
| 做完第一套練習嘅比例 | ≥ 50% |
| 第 1 日回頭率 | ≥ 40% |
| 第 7 日回頭率 | ≥ 20% |
| 試用轉付費 | ≥ 5% |

風險：

- **版權**：動作可以自由用，但名稱、說明文字、分級編號都要自己寫，唔好抄書。
- **健康責任**：要有清楚聲明；身體測試只講「偏緊」，唔好講「診斷」。
- **競爭**：市面已有好多伸展 app。我哋嘅分別係 3D 肌肉發光、身體地圖、專攻 office 族。
- **網頁版限制**：iPhone 網頁推送通知要先「加到主畫面」，提醒效果可能較弱。
